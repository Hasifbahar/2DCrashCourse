# Java Hero 🎮🤖

**Java Hero** is an interactive, 2D top-down RPG educational game designed to teach basic Java programming concepts through immersive and engaging gameplay. Players step into a broken digital world, taking on coding-based challenges to solve puzzles, bypass obstacles, and restore structural balance to the system.

🔗 **Repository Link:** [https://github.com/Hasifbahar/2DCrashCourse](https://github.com/Hasifbahar/2DCrashCourse)

---

## 🌟 Overview & Experience

The core mission of *Java Hero* is to make programming beginner-friendly, rewarding, and deeply educational. 

* **Theme:** Adventure, Fantasy, and Education.
* **Player Experience:** Players act as heroes on a quest inside a futuristic programming facility. Guided by an AI Supervisor, they must troubleshoot failing automation systems by structuring logic commands for inactive "Worker Units."
* **Target Audience:** * Beginner programming students.
    * Secondary school students learning Java.
    * Anyone looking for a gamified introduction to coding.

---

## 🛠️ Design Pillars

1.  **Learning Through Gameplay:** Programming syntax and concepts are fundamentally stitched into progression.
2.  **Problem-Solving Progression:** Challenges steadily scale from basic data typing to complex loop nesting.
3.  **Interactive Coding Challenges:** Mechanics emphasize drag-and-drop or fixing faulty scripts directly in-game.
4.  **Reward-Based Advancement:** Overcoming bugs rewards players with exploration items and algorithmic milestones.
